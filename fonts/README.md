# Шрифты (исходники «Чтеца шрифтов»)

Файлы перенесены сюда из папки Google Drive «Чтец шрифтов — исходники»
(там же лежат `chitatel-cycle-01…15.zip`, `exact.txt`, «Как пользоваться.md»).

| файл | размер | что это |
|---|---|---|
| `ComicsCyr.ttf` | 77 024 Б | комиксный кириллический шрифт |
| `MangaCyr.otf` | 100 540 Б | манговый кириллический шрифт |
| `AnimeAceCyr.ttf` | 45 228 Б | «кричащий» аниме-шрифт с кириллицей |

Это материал для генерации обучающих страниц, а не модели распознавания.
**В `koma-web.html` они не вшиты** и не будут: файл читалки — про чтение
страниц, а не про генерацию шрифтовых картинок.

Модели распознавания из того же набора (`best_r28_final.onnx`,
`best_finetuned_r4.onnx`, `best_base_r3.onnx`, `charset.txt`) в репозиторий
не кладутся: они крупные и в читалке необязательны — основной распознаватель
работает без них.

Замер 27.10 на облачках со скриншотов (`CER`, меньше — лучше):

| облачко | основной | `best_r28_final` | `best_finetuned_r4` | `best_base_r3` |
|---|---|---|---|---|
| «ЛУЧШЕ БЫТЬ БОЛЕЕ РАВНОДУШНЫМ.» | 0 % | 4,0 % | 8,0 % | 92 % |
| «…ПЛОХИЕ ПАРНИ.» | 0 % | 5,2 % | 8,6 % | 91,4 % |
| «НО РАЗВЕ НАШ ЛИДЕР…» | 5,9 % | 17,6 % | 17,6 % | 88,2 % |
| «ГДЕ, ЧЁРТ ВОЗЬМИ…» | 14,7 % | 73,5 % | 73,5 % | 97,1 % |

Поэтому в читалке эти модели — **необязательный второй распознаватель**
(⚙ → Модели → `line32.onnx` / `best_r28_final.onnx` + `charset.txt`):
подключается только на трудных строках, и вариант берётся лишь если в нём
больше слов из словаря, чем у основного. Верные строки не трогаются.
