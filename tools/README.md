# tools/ — тесты, словарь и обучение модели живут здесь, в репозитории

Раньше всё это лежало в рабочей песочнице и во `/tmp`: сборка словаря делалась
одноразовым скриптом, замеры — пробами, обучение не делалось вовсе. Теперь это
файлы репозитория: их можно запустить заново и получить тот же результат.

```
tools/
  rec_charset.txt        азбука распознавателя: 517 символов (класс 0 — blank, 518 — «неизвестно»)
  charset.py             азбука, раскладка классов, CER, жадный разбор
  synth.py               синтетические строки: слова из вшитого словаря + шрифты + порча
  model.py               CRNN по контракту koma_rec.onnx (вход [1,3,48,W], выход [1,T,519])
  train_rec.py           обучение CTC: на синтетике или на своих кропах
  export_onnx.py         .pt → .onnx + проверка (формы, вероятности, расхождение с torch)
  check_onnx_contract.py подойдёт ли ЛЮБОЙ .onnx приложению
  bench.py               тренировочная площадка: обучение → ONNX → отчёт, одной командой
  build_dict.py          сборка вшитого словаря (487 247 слов) с проверкой md5
  selftest.py            быстрая самопроверка инструментов (без torch и без сети)
  dict_header.txt, dict_tail.txt, dict_md5.txt   части и отпечаток part0-dict.js
  requirements.txt, requirements-train.txt
```

## Быстрые команды

```bash
pip install -r tools/requirements.txt        # проверки, словарь, синтетика
python3 tools/selftest.py                    # 14 проверок, нужен только python
python3 tools/build_dict.py --check          # сверить вшитый словарь (md5, 487 247 строк)
python3 tools/check_onnx_contract.py путь/к/модели.onnx
```

Обучение (нужен torch, ~200 МБ):

```bash
pip install -r tools/requirements-train.txt
python3 tools/bench.py                       # короткий прогон: ~10 минут на 2 ядрах
python3 tools/train_rec.py --steps 4000 --epochs 40 --out runs/rec.pt
python3 tools/export_onnx.py --ckpt runs/rec.pt --out models/rec.onnx
```

Своя разметка вместо синтетики: каталог с кропами строк и файл `labels.tsv`
в формате `путь<TAB>текст` (10-я строка каждого десятка уходит в проверку):

```bash
python3 tools/train_rec.py --crops data/lines --labels data/labels.tsv \
        --steps 3000 --epochs 40 --out runs/manga.pt
```

В GitHub Actions: `.github/workflows/ci.yml` — тесты страницы, `selftest.py` и
проверка контракта модели; `.github/workflows/train.yml` — обучение вручную
(Actions → Run workflow), готовый `.onnx` и отчёт возвращаются артефактом.

## Контракт модели — то, что нельзя менять

Приложение (`part3.js`, `recProbs`/`decodeCrop`/`beamDecode`) ждёт ровно это:

| | |
|---|---|
| вход | `float32 [1, 3, 48, W]`, значение `(пиксель/255 − 0,5)/0,5`, W = max(320, 48·w/h), хвост дополнен **нулями** (= серый 128) |
| выход | `float32 [1, T, 519]`, T = W/8, значения — **вероятности** (сумма по классам = 1) |
| классы | 0 — blank, 1…517 — `rec_charset.txt` по порядку, 518 — «неизвестно» |

Поэтому обученный файл просто подкладывается в приложение через ⚙ → Модели и
работает со словарным beam-декодером без правок кода. `check_onnx_contract.py`
проверяет все три пункта, в том числе то, что на пустой картинке побеждает blank.

## Что здесь честно ограничено

- **Только CPU.** GPU в песочнице и на раннере GitHub Actions нет. Модель на
  0,97 млн параметров за 10–20 минут доходит до читаемых строк; большая
  `koma_rec` (7,9 МБ) на CPU учится сутками — её так не переобучить.
- **Синтетика — не манга.** Обучение по умолчанию рисует строки шрифтами
  (DejaVu) и портит их: наклон ±0,32, размытие, шум, инверсия, блики, обрезка.
  Это проверяет весь путь «данные → модель → ONNX → приложение», но не заменяет
  разметку настоящих страниц: на настоящей манге цифры будут другими.
  Для настоящего улучшения нужны кропы строк с транскриптами (`--crops`).
- **Ничего не уходит в сеть.** Слова для синтетики берутся из вшитого словаря
  `part0-dict.js`, шрифты — системные.
- **Словарь не 3 млн.** 250 000 частотных + 237 247 словоформ = 487 247 строк:
  замер показал, что больше — те же 11,7 % CER, но втрое дольше старт.
  Подробности — в шапке `build_dict.py` и в отчёте `Словарь-3-миллиона-27-10.md`.
